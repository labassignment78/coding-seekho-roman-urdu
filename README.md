# Roman Urdu Me Coding Seekho

Ye repo un students ke liye hai jo coding seekhna chahte hain lekin English tutorials se pareshan ho jate hain. Yahan har cheez **Roman Urdu** me samjhayi gayi hai — aasan lafzon me, chhoti examples ke saath.

## Ye kis ke liye hai?

- Jo bilkul zero se shuru kar raha hai
- Jise English samajhne me mushkil hoti hai
- Jo school, college ya academy me parh raha hai
- Jo apne phone ya laptop par coding seekhna chahta hai

## Zaroori baat

Coding seekhne ke liye English aana zaroori **nahi** hai. Code ke lafz (jaise `print`, `if`, `function`) English me hi hote hain, lekin unka matlab samajhna aasan hai. Is repo me aap ko har lafz ka matlab Roman Urdu me milega.

## Kaise use karein?

1. Lessons ko **tartib se** parhein — pehle HTML, phir CSS, phir JavaScript, phir Python.
2. Har example ko **khud likh kar** chalayein. Sirf parhne se coding nahi aati, likhne se aati hai.
3. Har lesson ke end par **practice exercises** hain — unko zaroor karein.
4. Galti ho jaye to ghabrayein nahi. Galti coding ka hissa hai, har programmer se hoti hai.

## Tools (sab free hain)

- **HTML/CSS/JavaScript** ke liye: koi bhi browser (Chrome) aur Notepad ya VS Code.
- **Python** ke liye: [python.org](https://www.python.org) se Python install karein, ya phone par Pydroid 3 app use karein.

## Aage kya?

Ye sirf shuruaat hai. Buniyad mazboot ho jaye to aap aage websites, apps aur apne projects bana sakte hain. Seekhte raho, banate raho!
